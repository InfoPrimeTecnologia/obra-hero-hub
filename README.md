# Mestre 360 Sistema

Vamos começar a construir um sistema chamado Mestre 360, a logo está em anexo.
Esse sistema será focado na area de obras, mas vamos construir essa parte mais tarde. Iremos começar construindo um painel de administrador onde será possivel ver uma dashboard com metricas do sistema e clientes, em seguida uma aba de clientes cadastrados no sistema, uma aba de planos para cadastro de planos do sistema, uma aba de Faturas para acompanharmos as faturas geradas pelo sistema, uma aba de tickets de suporte para verificarmos os tickets de suporte de clientes do sistema.
Vamos integrar o sistema com a api do ASAAS para ser nosso gateway de pagamento.
Devemos tambem consegui enviar emails de boas vindas aos clientes e avisos de faturas emitidas e vencidas, devemos tambem conectar com uma api do whatsapp que irei fornecer para enviar whatsapp aos clientes, tanto de boas vindas como de aviso ou cobrança.
